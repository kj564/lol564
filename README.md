# 🎮 2048 NEON

Game web **2048** dengan estetika neon modern, animasi ubin yang halus, dan dukungan penuh untuk keyboard & sentuh (swipe) di mobile.

> 🎯 Gabungkan ubin dengan angka yang sama hingga mencapai **2048**!

## ✨ Fitur

- 🌈 **Tampilan neon/cyberpunk** — gradien warna per nilai ubin dengan efek glow
- 🎬 **Animasi halus** — ubin meluncur, menyatu, dan muncul dengan transisi cubic-bezier
- ⌨️ **Kontrol fleksibel** — panah, WASD, HJKL, dan **geser (swipe)** di layar sentuh
- ↩️ **Undo** hingga 20 langkah terakhir
- 🏆 **Skor & Rekor** tersimpan otomatis di `localStorage` browser
- 📱 **Responsif** — optimal di HP maupun desktop
- 🎉 **Layar menang/kalah** dengan opsi lanjut bermain setelah 2048
- 💾 **Tanpa dependensi** — 1 file HTML murni, tanpa build step

## 🚀 Cara Main

1. Buka game di [GitHub Pages](https://kj564.github.io/lol564/)
2. Gunakan tombol panah (desktop) atau geser layar (mobile) untuk menggerakkan ubin
3. Ubin dengan nilai sama akan menyatu & nilainya berlipat ganda
4. Capai ubin **2048** untuk menang — lanjutkan untuk skor setinggi-tingginya!

### Pintasan Keyboard

| Aksi | Tombol |
|------|--------|
| Gerak | `←` `↑` `↓` `→` atau `W A S D` |
| Undo | `U` |
| Game baru | `R` |

## 🛠️ Teknologi

- HTML5, CSS3 (Grid, Custom Properties, Animations)
- JavaScript murni (Vanilla, tanpa framework)
- Tanpa dependency eksternal — fully self-contained

## 📦 Deploy

Game ini adalah file statis tunggal. Cukup upload `index.html` ke GitHub Pages, Netlify, Vercel, atau hosting statis apa pun.
