🌍 Harvest Vale Demo

Single-file demo menggabungkan: 5-layer tilemap, Cinemachine camera, Tab menu, drag-drop inventory, dan item pickup system.

🎯 Features

  • 5-Layer Tilemap: Ground → WalkInFront → Collision → Player → Canopy → Decor
  • Cinemachine Camera: smooth lerp follow + confiner clamp
  • Tab Menu: 3 pages (Status/Bag/Map), input blocking saat open
  • Drag-Drop Inventory: 12 slots, swap via HTML5 D&D API
  • Item Pickup: circle collider (Euclidean dist) + stacking + destroy

🧪 Try It

  • Walk karakter ke item di tanah → auto-pickup (toast + popup)
  • Item stackable (carrot, potion) akan numpuk di slot yang sama
  • Item unik (sword, axe) isi slot kosong
  • Tekan Tab buka Bag, drag item untuk swap posisi
  • Tekan R untuk respawn items di world
